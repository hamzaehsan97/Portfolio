# Hamza Ehsan — Portfolio

A focused, single-page portfolio built with React and Vite. The site is organized into Home, Career, Selected Work, Writings, Life, and Contact sections.

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and publish it to GitHub Pages with `npm run deploy`.

[View the portfolio](https://hamzaehsan97.github.io/Portfolio/)
