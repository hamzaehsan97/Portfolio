# Hamza Ehsan — Portfolio

A focused portfolio built with React and Vite. The production build pre-renders the home page plus dedicated Career, Work, StackPilot, Writing, About, and Résumé routes so the core content is available without JavaScript.

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and publish it to GitHub Pages with `npm run deploy`.

The build also publishes `robots.txt`, `sitemap.xml`, `llms.txt`, canonical metadata, and `ProfilePage`/`Person` JSON-LD for `hamzaehsan.com`.
